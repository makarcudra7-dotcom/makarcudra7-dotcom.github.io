## Нерешённые внешние вопросы

1. HTTPS: https://makarcudra7-dotcom.github.io/ отвечает 301 с Location http://provkus-media.ru/. Главная HTTP-версия отвечает 200. HTTPS-версия основного домена недоступна из этой среды (502 сетевого шлюза). Проверить сертификат и Settings → Pages → Enforce HTTPS. Нельзя утверждать, что ошибка 502 возникает у всех посетителей, но перенаправление на HTTP подтверждено.
2. Фактическая индексация неизвестна: Search Console не подключена. Для всех статей она явно отмечена как unknown_requires_search_console в live-url-audit.json. HTTP-ответ 200 и присутствие в sitemap не означают индексацию. Публичный поиск по домену результатов не дал; это также не доказывает отсутствие страниц в Google.
3. В Search Console после исправления HTTPS: отправить https://provkus-media.ru/sitemap.xml, проверить главную и все 24 URL через «Проверка URL», выбранный Google canonical, причины исключения и дату последнего обхода. Затем проверить отчёты «Страницы», «Основные интернет-показатели», «Меры, принятые вручную», «Проблемы безопасности» и Discover, если он доступен.
4. Полная браузерная проверка и измерение Core Web Vitals не выполнены: браузер в среде отсутствует, загрузка Chromium завершалась сетевым тайм-аутом. Перед публикацией нужен визуальный просмотр на телефоне и компьютере.
5. Биографии содержат заявления о профильном образовании без конкретных подтверждений. Редакции следует проверить их фактическую точность; образование и опыт не выдумывались и не дополнялись в этом изменении. Полная фактологическая экспертиза советов по пищевой безопасности не проводилась.
6. Старые ручные workflow «relaunch/final polish/rebuild editorial» могут перезаписать контент и изображения. Не запускайте их без проверки изменений; новый сборщик индексов не меняет статьи.
