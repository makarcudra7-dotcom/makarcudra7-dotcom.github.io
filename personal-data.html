Обработка персональных данных

Этот документ описывает данные, которые пользователь добровольно передаёт через формы ProVkus, цели такой передачи и способы отказаться от дальнейшей обработки.

1. Данные при вопросе автору

Через форму «Задать вопрос автору» пользователь может передать имя, адрес электронной почты и текст вопроса. Цель обработки — получить обращение, передать его редакции, подготовить ответ и при необходимости использовать саму тему вопроса при подготовке редакционного материала.

Адрес электронной почты и имя пользователя не публикуются в материале без отдельного согласия. Отправка вопроса не включает пользователя в список рассылки.

2. Данные при подписке

Подписка на новые материалы оформляется отдельно. Для неё обрабатывается адрес электронной почты, указанный пользователем. Цель — доставка уведомлений о новых публикациях ProVkus до момента отписки или отзыва согласия.

3. Согласие

Перед отправкой каждой формы пользователь самостоятельно ставит обязательную отметку согласия. Без этой отметки форма не отправляется. Согласие на вопрос автору и согласие на рассылку являются разными действиями и не подменяют друг друга.

4. Сторонние сервисы

Для доставки вопроса редакции используется FormSubmit и почтовая инфраструктура Gmail (Google). Для подписки на новые материалы используется follow.it. Перед передачей данных в эти сервисы пользователь получает соответствующее уведомление непосредственно рядом с формой.

Поскольку перечисленные сервисы являются сторонними и могут обрабатывать данные за пределами Российской Федерации, владельцу проекта необходимо самостоятельно обеспечить соблюдение применимых требований к трансграничной передаче персональных данных до начала такой обработки.

5. Срок и прекращение обработки

Редакционная переписка хранится не дольше, чем это необходимо для ответа и работы с обращением, если более длительное хранение не требуется по закону или для защиты законных интересов. Данные подписки обрабатываются до отписки пользователя либо прекращения работы рассылки. Сроки хранения у сторонних сервисов дополнительно определяются их правилами.

6. Отзыв согласия

Чтобы попросить удалить данные из редакционной переписки или отозвать согласие на их обработку редакцией, напишите на makarcudra7@mail.ru. От e-mail-рассылки можно отказаться по ссылке отписки в полученном письме.

7. Ответственное лицо

Контактные сведения учредителя и главного редактора проекта приведены на странице «Контакты». Политика конфиденциальности размещена на странице «Конфиденциальность».
